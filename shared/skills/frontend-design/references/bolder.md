# Bolder

Includes modified guidance from Impeccable. See [sources](SOURCES.md).

Amplify the named target, not the whole product. Preserve neighboring surface, behavior, claims, and the incumbent palette, type, corners and elevation primitives. If the request is to choose a bolder new identity, use [shape](shape.md); do not disguise redesign as refinement. Flag a truly necessary new primitive before adding it.

1. Compare the target with the system's strongest neighboring examples. Which existing motifs, type steps, pacing or structure did the target opt out of? Decide what should lead and what should go quiet.
2. Amplify that device decisively. Try a different spatial role, stronger hierarchy, fuller use of an existing color region, an artifact with a real job, or a different local rhythm. Do not raise size, saturation and motion on everything at once.
3. Strip the words from the sketch. Does the arrangement itself reveal why this section matters? If its only force is bigger text, change the composition. If it needs evidence, name the asset, what it proves, and where it anchors; never invent proof.
4. Render with real copy. Confirm the same brand, truthful claims, stable surrounding surface, expected controls and responsive behavior. The target should be a peak in the rhythm, not a second identity. Finish with [polish](polish.md).
