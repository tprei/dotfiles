## Retained policy contract

The patch adds `cfgMainAgentDisabledProviders`, registered as `mainAgent.disabledProviders: string[]`, default empty. `isMainAgentProviderDisabled(settings: Settings, agentKind: "main" | "sub", provider: string): boolean` always returns false for subagents. `assertMainAgentProviderAllowed(settings: Settings, agentKind: "main" | "sub", provider: string): void` throws the existing disabled-main-driver error only for prohibited main-session providers.

Retain enforcement at initial main model, direct and temporary switches, cycling/listing, resumed sessions, stream dispatch, retry fallback candidates/apply/eligibility, usage-aware fallback, Fireworks fast fallback, and fallback reversion. Assign `#agentKind` before checking/wrapping initial model/stream and remove its later duplicate assignment. Add `agentKind(): "main" | "sub"` to model-controls/recovery hosts and their real/fixture callers. No new provider policy, errors, fallback rules, or configuration aliases.

Upstream v18.12.4 extracts fallback-chain discovery to `retry-fallback-chains.ts`. Keep the original patch's filtering at the session's actual provider-selection boundaries, preserving the new `currentModel` and `options` arguments. Upstream `findRetryFallbackCandidates(role: string, currentSelector: string, currentModel: Model | null | undefined = this.#host.model(), options?: { wrapAround?: boolean }): RetryFallbackSelector[]` must retain its new signature. Do not change shared chain resolution merely to fit old patch context. Port all existing consumer-visible policy tests; adjust fixtures for the new hosts. No static-source tests, suppressions, new comments, shims, or swallowed failures.

Global `disabledProviders` is not equivalent: it also restricts subagents. Root, mix, and china intentionally prohibit `antigravity-cli` for the main driver while advisor/commit/surveyor agents use it. Retain the AGY CLI bridge, SQLite read protection, expensive-agent concurrency cap, Herdr state, and Moshi hooks because upstream does not replace their contracts. Retain `/use` because it applies session-only role overrides, while native `/modelpreset` persists and replaces roles. Retain `/m` because it has custom fuzzy ranking and latest-version preference.
